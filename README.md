# Лендинг-опросник для GitHub Pages

Состав:

- `index.html` - лендинг;
- `assets/` - шесть исходных изображений;
- `../ai-quiz-google-apps-script/Code.gs` - скрипт, который записывает голоса в Google Таблицу и возвращает статистику.

## Подключение Google Таблицы

1. Откройте Таблицу голосов и выберите `Расширения` -> `Apps Script`.
2. Удалите стартовый код, вставьте весь файл `Code.gs` и сохраните.
3. Нажмите `Развернуть` -> `Новое развертывание` -> выберите тип `Веб-приложение`.
4. Укажите: `Выполнять от имени` - `Я`; доступ - `Все` без входа в Google.
5. Нажмите `Развернуть`, подтвердите доступ к своей Таблице и скопируйте ссылку, заканчивающуюся на `/exec`.
6. В начале `index.html` замените значение `GOOGLE_SCRIPT_URL` на эту ссылку.

Если вы меняете `Code.gs` позже, откройте `Развернуть` -> `Управление развертываниями`, отредактируйте текущее веб-приложение, выберите новую версию и снова нажмите `Развернуть`. Ссылка `/exec` останется той же.

Посетители сайта не будут видеть Таблицу, входить в Google или подтверждать доступ. Скрипт хранит дату, название опроса, выбранный вариант и случайный идентификатор браузера.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в его корень `index.html`, `README.md` и папку `assets`.
2. Откройте `Settings` -> `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/(root)`.
4. После публикации QR-ссылки используйте в виде:
   - `https://USERNAME.github.io/REPOSITORY/#grach`
   - `https://USERNAME.github.io/REPOSITORY/#volk`
   - `https://USERNAME.github.io/REPOSITORY/#osetr`

## Ограничение голосов

Один браузер получает UUID в `localStorage`. Таблица дополнительно не принимает второй голос с тем же UUID в том же опросе. При открытии страницы сайт сверяет локальный голос с Таблицей: если запись удалена, варианты снова становятся доступны. Это ограничение для обычного посетителя, а не защита от намеренной накрутки: очистка хранилища или другой браузер создадут новый UUID.
